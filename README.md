# Stargazer Locator

A command line tool that calculates which constellations are currently visible above the horizon from a given country location, along with their coordinates.

## Installation and Setup

1. Clone or download these project files into a folder.

2. Open your terminal or command prompt inside that folder and create a virtual environment:
python -m venv venv

3. Activate the virtual environment:
On Windows: venv\Scripts\activate
On macOS/Linux: source venv/bin/activate

4. Install the required external libraries:
pip install -r requirements.txt

5. Run the application:
python main.py
